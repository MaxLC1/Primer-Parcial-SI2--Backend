# Backend FastAPI - Tienda Ropa AR

Repositorio para el backend de la plataforma de comercio electrónico con vestidores virtuales.

## Tecnologías
*   Python 3
*   FastAPI
*   PostgreSQL
*   Integración con IA y pasarelas de pago

## Casos de Uso (Ciclo 1)
*   CU-01: Iniciar Sesión
*   CU-02: Registrar cuenta de cliente
*   CU-03: Gestionar usuarios y roles
*   CU-04: Administrar ciudades y sucursales
*   CU-05: Gestionar productos de ropa
*   CU-06: Gestionar tallas, colores, categorías y temporadas
*   CU-07: Gestionar proveedores
*   CU-08: Gestionar temporadas y colecciones
